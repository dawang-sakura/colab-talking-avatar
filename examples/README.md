# 示例文件

| 文件 | 说明 |
|---|---|
| `host.png` | 示例角色图（941×1672 竖图）。**此图由 AI 生成，为虚构人物，非真实人物。** 文件内保留了生成工具写入的 C2PA 内容凭证（标明为 AI 生成）。 |
| `script.txt` | 示例台词，3 句，念完约 8～12 秒（估算）。内容与 notebook「① 台词」格里的默认台词相同。 |

notebook 默认使用 `examples/host.png`（「①-2 设置」里「角色图路径」的默认值），运行时会自动从本仓库下载，不需要手动上传。

换成自己的图时，请只用你本人、已取得当事人同意、或 AI 生成的虚构人物的照片。图片建议：竖图、正面、闭嘴、脸够大、手不入镜。
