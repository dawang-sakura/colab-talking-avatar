## 整个过程是怎么做的

按顺序，notebook 里每一格做一件事：

1. **① 台词**、**①-1**、**①-2**、**①-3**、**①-4**：你在这里输入台词、调整设置、上传文件。①-1 用来选模板，①-4 用来存模板，其余格子都是设置。
2. **② 环境检查**：显示 GPU 型号，获取示例文件，并确认要用到的文件都在。
3. **③ 配音**（「声音」选饶舌时改成「饶舌生成」，见下方「饶舌模式」）：默认先用声音包里的参考音，或者按你的文字描述生成一种新声音（即音色设计，只生成一次，存为参考音）。接着一句一句生成配音（每句最多 80 字，超过会自动切分）。句子之间会插入停顿，再拼接成一条完整音轨。同时记下每句话的起止时间，用作字幕的时间轴。最后删除配音模型，把显存腾出来。
4. **③-2 字幕准备**：下载字体，检查字体缺不缺字。有问题的话，在对嘴之前就会报错。
5. **④ 对嘴**：先按你选的画面比例和裁切位置把角色图裁好，再让角色跟着配音开口说话。视频长度会跟配音保持一致。
6. **⑤ 合成**：把画面和原始配音合在一起。「版面」选「上主播下录影」时，还会和录影合成 1080×1920，并混好声音。然后把字幕烧进画面。去背景关闭时，在这里打包下载。
7. **⑤-2 去背景输出**（「去背景」不是「关」时才做）：做出透明背景的视频，连同 ⑤ 的文件打包成 `talking_avatar_outputs.zip` 下载（一次只会自动下载一次）。
8. **⑥ 只重做字幕**（换字幕样式时才用，点「全部运行」时会自动跳过）。

工具与技术细节，请看最后的「给开发者的技术说明」。

- 「① 快速开始」：
  - **① 台词**：只有台词。这一格的代码是展开的，直接改三个引号之间的句子。
  - **①-1 选模板、上传录影和背景音乐**：「模板名称」填模板名称（留空＝不用模板）；「上传录影」「上传背景音乐」勾选后可以上传录影、背景音乐。见下方「模板」。
- 「进阶：建立／修改模板」（这一段在 notebook 里默认收起，点标题左边的箭头就能展开；如果用现成模板就不用看）：

每一格做完，会出现绿色的「✅」框。比较久的步骤（③-1 配音、④-2 下载模型、④-5 对嘴），开头会出现黄色的「⏳ 进行中」框，上面写着作者实测的大约耗时。

### 上传文件（①-3，选填）

要用自己的角色图、录影、背景音乐、字体文件、参考录音时，在 ①-3 勾选对应的项目（「上传角色图」「上传录影」「上传背景音乐」「上传字体文件」「上传参考录音」）。运行到这一格时，每一项会出现一个「选择文件」按钮。上传后，会自动把 ①-2 里对应的路径（「角色图路径」「录影路径」「背景音乐路径」「字体文件路径」「参考录音路径」）指到上传的文件。

- **全部不勾＝什么都不做**，点「全部运行」时不会停在这里。
- **每项只能选一个文件。** 选了多个，会报错停下（文件已经放进 `/content/`，可以重新运行 ①-3 只选一个，或者直接在 ①-2 填路径）。点取消也会报错停下；但如果这一项之前已经上传过，就会接着用之前的文件。
- **上传记录会保留**（存在 `/content/.talking_avatar_uploads.json`，删除运行时后就没了）：之后重跑 ①-2（例如调版面，再只跑 ⑤），或者「重启会话」后重跑，都照样用上传的文件。上传完可以把勾取消。
- **和 ①-2 填的路径冲突时**：用上传的文件。之后你在 ①-2 把那个路径改成别的值，就改用 ①-2 填的路径（这一项的上传记录作废）。勾 ①-3 的「清除上传记录」＝全部改回 ①-2 填的路径。
- 录影很大（几百 MB）时，在 ①-3 上传可能很慢。建议改在左侧「文件」面板上传，再到 ①-2 填「录影路径」。
- 上传的项目如果用不到（例如上传了录影，但版面是「只有主播」；上传了字体，但「字幕字体」没选「自定义」），会提醒你。
- **验证状态**：①-3 的上传功能（包括选择文件、取消或多选时的处理、保留上传记录），目前只在作者自己的电脑上模拟测试过，还没有在 Colab 上实际点过。如果遇到问题，请改用左侧「文件」面板上传，再去 ①-2 手动填写路径。

### 模板（①-1、①-4，选填）

模板＝一个角色的固定设置。它存在你自己的 Google 云端硬盘「`talking_avatar_templates`」文件夹里（一个模板一个文件夹，换电脑也读得到）。存好之后，每做一支新片，只要：

1. 在 ① 台词里换上新台词。
2. ①-1 的「模板名称」填模板名称。模板的版面是「上主播下录影」时，勾「上传录影」上传录影（背景音乐可选）。
3. 点「全部运行」。「进阶」那一段完全不用打开。

| 会存进模板 | 不会存（每次自己给） |
|---|---|
| 人物：角色图（图片文件本身）、画面描述、主播上裁、画面比例、裁切位置、去背景 | 台词 |
| 声音：声音、声音描述、随机种子、句间停顿；声音克隆的开关、参考录音文件本身、参考录音文字；当「声音」选「自定义」时，还会存下生成的参考音 | 录影路径、背景音乐路径 |
| 字幕：显示字幕和全部字幕设置（「字幕字体」选「自定义」时，连字体文件一起存） | 省显存模式（要看这次的机器） |
| 版面：版面、录影上裁、录影下裁、录影左右位置、保留录影原声、补边模糊度、补边亮度 | 确认已获同意（声音克隆的同意声明，每次都要在 ①-2 自己勾） |

- **建立模板**：
  1. 把 ①-1 的「模板名称」留空。
  2. 在 ①-2 里把各项设置调好（自己的文件通过 ①-3 上传）。
  3. 在 ①-4 的「新模板名称」里填上你想取的名字。
  4. 点「全部运行」。
  5. 存完把名称清空，免得之后每次点「全部运行」都再存一次。

  已经有同名模板时，会停下；要覆盖就勾「覆盖同名模板」。
- **自定义声音要跑过 ③-1，才存得完整**：「声音」选「自定义（按声音描述）」时，设计声音每次的结果都不同。所以模板要连 ③-1 生成的参考音一起存，下次直接拿它当参考音，音色才会一模一样。①-4 运行时，如果参考音还没生成，会提示你。点「全部运行」时，③-1 做完会自动补存进模板。如果只运行 ①-4，请在跑完 ③-1 后，再运行 ①-4 一次。之后在 ①-2 改了「声音描述」或「随机种子」，就会重新设计音色（音色会变）。
- **用模板**：①-1 填了名称，才会请你授权读取 Google 云端硬盘（不用模板就不会问）。名称打错会停下，并列出现有的模板。模板里的文件会复制到 `/content/talking_avatar_template/`，「重启会话」后也还在。
- **修改模板**：
  1. 在 ①-1 填入这个模板的名称。
  2. 依次运行 ①-1、①-2（运行 ①-2 时会列出该模板当前的设置）。
  3. 在 ①-2 改你要改的项目，再运行 ①-2。
  4. ①-4 填同一个名称，运行 ①-4。

  注意：①-2 的表单显示的不是模板里的值。模板载入后，第一次运行 ①-2 时表单的值，会当成比较的基准；之后你在表单里改过的项目，才会覆盖模板（下面「跑完后只想改一部分」也是靠这个）。换成另一个模板时，基准会重新算。
- **删除模板**：直接去你的 Google 云端硬盘里，把对应模板的文件夹删掉就行。
- **验证状态**：模板功能（读写云端硬盘、①-1 上传、点「全部运行」时的覆盖顺序、自定义声音参考音的补存），只在作者的电脑上用模拟的方式验证过，还没在 Colab 上实际跑过。notebook 里设了让「进阶」那一段默认收起来，但 Colab 打开时有没有真的收起来，还没确认；没收起来也能照常运行。

### 跑完后只想改一部分：改哪格、跑哪格

都要在删除运行时之前做。用了模板，也照这张表改 ①-2：模板载入后，你在 ①-2 改过的项目会覆盖模板（想留下来的话，用 ①-4 存回模板）。

| 想改什么 | 改哪里 | 然后依次运行 |
|---|---|---|
| 字幕样式、字幕开关 | ①-2「字幕」（自定义字体也可以在 ①-3 上传） | ①-2（如果用了 ①-3 就再运行 ①-3）→ ⑥ |
| 版面微调（「上主播下录影」里的录影上裁、录影下裁、录影左右位置、主播上裁、补边模糊度、补边亮度、保留录影原声） | ①-2「版面」 | ①-2 → ⑤ |
| 换背景音乐 | ①-2 的「背景音乐路径」，或者在 ①-3 上传 | ①-2（如果用了 ①-3 就再运行 ①-3）→ ②-2 → ⑤ |
| 台词、声音、角色图、画面比例、去背景、录影、省显存模式 | ①／①-2／①-3 | 点「全部运行」（会重新配音和对嘴） |
| 饶舌：换一版（节奏、念法不满意） | ③-1 的「饶舌随机号」换一个数字 | 只运行 ③-1 先试听；满意了点「全部运行」（会重新对嘴） |

## 饶舌模式（默认关闭）

给一段歌词，AI 会自己配上 beat 来饶舌，再让角色跟着饶舌的人声对嘴。成片的声音是**带 beat 的完整版**。

### 要填什么

1. **①-2 设置**：「声音」选「饶舌（AI 生成）」，「饶舌声线」选女声或男声。
2. **① 台词**：改写成歌词，一行一句。
3. 点「全部运行」。其他设置（角色图、画面比例、版面、字幕）照常用。

- 「画面描述」没改过的话，会自动换成「跟着节奏点头、肩膀律动」的英文描述（例如 `A female rapper performing to a hip hop beat, nodding head to the rhythm, shoulders bouncing, subtle body groove, facing camera.`）。你自己改过就照你写的。
- 歌词里行首的秒数（`14.0｜`）和句首的语气括号（`(兴奋)`）用不到，会自动忽略。
- 不能和「声音克隆」一起用（开着会报错停下，请先取消勾选「开启声音克隆」）。
- 模板：「声音」「饶舌声线」会存进模板；「饶舌随机号」「先试听再对嘴」不会存（随机号是跟着这次的歌词挑的）。

### 歌词写多长

**建议每句 8～10 字、10 句以内。** AI 不会一字不差照念：歌词太密时，会把几句压成一句、或整句吞掉。作者实测：10 句 99 字给 28 秒，第 6～8 句被压成一句半，有两句几乎没唱。

- 生成的长度按字数自动算：字数 × 0.23 秒 ＋ 前奏和收尾约 5 秒（99 字约 28 秒）。
- 超过 80 字、超过 10 句，或有一句超过 12 字时，③-1 会印出黄色提醒。**只是提醒，照样会生成**（这几个门槛是作者按一次实测抓的，不是定论）。
- 饶舌越长，对嘴越久：作者实测 28 秒约 39 分钟（L4）。

### 先听再决定（推荐）

对嘴要等 30～40 分钟，先听饶舌比较省时间。在 **③-1** 这一格的表单里：

| 栏位 | 默认值 | 说明 |
|---|---|---|
| 饶舌随机号 | `2025` | 换一个数字＝换一版饶舌（节奏、念法会不一样）。数字本身没有好坏 |
| 先试听再对嘴 | 不勾 | 勾选后点「全部运行」，做完饶舌就停在 ③-1 让你试听（出现蓝色的「⏸ 已暂停」框，不是出错） |

1. 勾「先试听再对嘴」，点「全部运行」。
2. ③-1 跑完会出现两个音频条（带 beat 的完整版、只有人声），并列出每句歌词有没有唱出来。
3. 不满意：把「饶舌随机号」换一个数字，再点 ③-1 左边的 ▶，重新生成（不用重跑前面的格子）。
4. 满意了：取消勾选「先试听再对嘴」，再点「全部运行」。**这一版会直接沿用，不会重新生成**（同样的歌词、声线、随机号，结果存在 `/content/rap/takes/` 里，删除运行时才会清掉）。

不勾「先试听再对嘴」的话，「全部运行」会直接往下做完对嘴和合成。

### 字幕

- 字幕文字**一律是歌词原文**（不用语音识别的字，它常写错，例如把「机子」写成「積子」）。
- 时间：用 faster-whisper 听人声里每个字在几秒，再用**拼音**跟歌词逐字对齐。
- **没唱出来、对不上的句子不上字幕**（一句歌词至少要对上一半的字），宁可空着，也不在错的时间显示。下一句被吞掉时，上一句念完就收掉，不会一直留着。
- 字幕样式照 ①-2 的设置；⑥「只重做字幕」也能用。
- 对齐工具跑不起来时，会改成按字数平均分配字幕时间（可能对不准），并印出黄色提醒，流程照常往下跑。

## 字幕（默认开启）

成品默认把字幕烧进画面，还会另外生成一份 `talking_avatar.srt` 字幕文件（可以导入剪辑软件，或上传到视频平台）。

- **文字**：直接用台词原文（不含句首的语气括号）。因为不做语音识别，所以不会有错别字。默认去掉逗号和句号（见下表「字幕去逗句号」）。
- **时间**：按每句配音的实际长度，加上「句间停顿」来推算。两句之间停顿时，上一句字幕会一直留着，直到下一句出现。
- **长句**：一行放不下时，会自动切成几段轮流显示。优先在标点后面切；只在词和词之间切（用 [jieba](https://github.com/fxsjy/jieba) 分词），「了、的、吗」这类助词不放在行首；jieba 装不上时，退回按字切。每段的时间按字数比例分配。
- 字号、边距、一行放几个字，都按画面尺寸推算，没有写死像素。

要调整字幕，请到 ①-2 设置格的「字幕」那一段（表单里有开关、滑块和下拉菜单）：

| 栏位（表单上显示的名称） | 默认值 | 说明 |
|---|---|---|
| 显示字幕 | 勾选 | 字幕总开关。取消勾选后，成品就不带字幕 |
| 字幕去逗句号 | 勾选 | 去掉字幕里的逗号和句号：删掉句尾的 `，。,.`，把句中的换成一个空格；`！？` 等其他标点保留，数字里的小数点和千分位逗号（`2.5`、`1,000`）也保留。例：「进了，三次免转。」→「进了 三次免转」。这项设置只影响字幕（画面上的字幕和 `.srt` 文件），配音仍照台词原样念。关掉后，字幕会照台词原样显示标点 |
| 字幕字体 | `思源黑体（粗）` | 选择字体的下拉菜单，见下方字体表。如果选「自定义（上传字体文件）」，就会改用「字体文件路径」里填的字体 |
| 字体文件路径 | `/content/my_font.ttf` | 用自己的字体文件：可以在 ①-3 勾选「上传字体文件」来上传 `.ttf`／`.otf`，或者先把文件传到左侧「文件」面板，再在这里填路径。请自行确认该字体允许你的用途（例如商用） |
| 字幕大小 | `100` | 单位是 %。100 代表画面短边的 1/12（480×832 的画面下约 40 像素）；滑块范围是 50～200 |
| 字幕效果 | `淡入` | 字幕出现的方式：无、淡入、淡入淡出、弹出、滑入、逐字（见下表） |
| 字幕位置 | `底部` | 底部、中间、顶部 |
| 字幕边距 | `12` | 字幕离画面下边缘（选「顶部」时是上边缘）的距离，占画面高度的 %；选「中间」时不用 |
| 字幕描边 | `8` | 描边的粗细，占字号的百分比（%）；填 0 就是不描边。默认是单层黑色描边 |
| 字幕颜色 | `#FFFFFF` | 字幕文字的颜色，格式为 `#RRGGBB` |
| 描边颜色 | `#000000` | 字幕描边的颜色，格式为 `#RRGGBB` |

字幕效果（都是 ASS 字幕的标准特效，由视频处理工具 ffmpeg 的 libass 绘制）：

| 效果 | 看起来 |
|---|---|
| 无 | 直接出现、直接消失 |

### 只重做字幕（换样式不用重跑）

跑完一次后，如果想换字幕样式，**请在删除运行时之前**做：

1. 修改 ①-2 的字幕设置。
2. 运行 ①-2。
3. 运行 **⑥ 只重做字幕** 这一格（如果用 ①-3 上传了新字体，请在运行 ①-2 之后先运行 ①-3）。

它会拿 `/content/output/` 里不带字幕的 `talking_avatar_nosub.mp4`，和字幕时间轴 `subtitle_timeline.json`，重新烧一遍字幕。不会重跑配音和对嘴。新的成品和字幕会打包成 `talking_avatar_resub.zip` 下载。

## 画面比例

在 ①-2 设置格，用「画面比例」下拉菜单选。像素总量都接近 480×832（对嘴底模是 480P），长和宽都是 16 的倍数。**作者实测过 9:16 和 1:1（624×624），都一次跑通；16:9、4:5、3:4 还没实测。**

| 画面比例 | 画面尺寸 | 常见用途 |
|---|---|---|
| 9:16 竖屏短视频（默认） | 480×832 | 短视频、限时动态 |
| 16:9 横屏视频 | 832×480 | 横屏视频 |
| 1:1 方形帖子 | 624×624 | 方形帖子 |
| 4:5 Instagram 竖版帖子 | 576×720 | Instagram 竖版帖子 |
| 3:4 小红书竖版 | 576×768 | 小红书 |

当角色图的比例和画面不一致时，程序会先裁切再缩放。裁切时只裁一个方向（图太宽就裁左右，图太高就裁上下），可以用「裁切位置」来决定保留哪一部分：

| 裁切位置 | 图太高（裁上下） | 图太宽（裁左右） |
|---|---|---|
| 偏上（保留头部，默认） | 保留上方 | 保留中间 |
| 置中 | 保留中间 | 保留中间 |
| 偏左 | 保留上方 | 保留左边 |
| 偏右 | 保留上方 | 保留右边 |

字幕的字号、边距、一行放几个字，都按实际画面尺寸推算，换比例不用另外调。对嘴做完之后再改「画面比例」不会生效（⑥ 只重做字幕，照现有视频的尺寸）。想换比例，要重新点「全部运行」。

## 去背景（默认关闭）

想把主播放进别的模板合成（例如直播版面）时用。在 ①-2 设置格，把「去背景」选成「绿幕（推荐）」或「逐帧」。这样除了一般的 `talking_avatar.mp4`，⑤-2 会再输出一份透明背景的 **`talking_avatar_alpha.webm`**：

- 这是带原始配音的透明背景视频。
- **画面里不烧字幕**（如果需要字幕，可以在你用来合成的模板里另外加，或者导入附带的 `talking_avatar.srt`）。普通的 `talking_avatar.mp4` 里照常有字幕，⑥ 只重做字幕也照常能用。
- 透明效果，要用支持透明 WebM 的软件才看得到；有些播放器会显示成黑底。

去背景用的工具是 [BiRefNet](https://github.com/ZhengPeng7/BiRefNet)（MIT 授权）。模型文件运行时从 Hugging Face 官方的 `ZhengPeng7/BiRefNet` 下载（版本已固定）。BiRefNet 和对嘴模型不会同时占用显存。

| 「去背景」 | 做法 | 优缺点 |
|---|---|---|
| 关（默认） | 不去背景 | — |
| 绿幕（推荐） | ④-3 在对嘴前，先用 BiRefNet 把角色图换成纯绿背景（用完立刻释放显存；换绿底前会先用 [pymatting](https://github.com/pymatting/pymatting) 估算前景色，去掉发丝里混入的原背景颜色）→ 进行对嘴 → ⑤-2 把绿色抠掉，并消掉边缘泛出的绿光 | 速度快，只多处理一张图。**注意：选这项时，`talking_avatar.mp4` 的背景会变成绿色。** 已知风险见下方「常见问题」 |
| 逐帧 | 角色图保持原样先做对嘴 → ⑤-2 先关掉 ComfyUI 释放显存，再用 BiRefNet 对成品视频的每一帧抠图，生成透明遮罩 | `talking_avatar.mp4` 能保留原图背景；但比绿幕慢（每一帧都要算），而且画面边缘在前后帧之间可能会轻微闪烁 |

绿幕路线的抠色参数写在 ⑤-2 这一格的开头，一般不用改。绿幕的实际颜色，会从第一帧的背景自动取。⑤-2 下载的压缩包里，会附上对嘴用的绿幕图 `input_greenscreen.png`。边缘不满意时，可以拿它对照：绿幕图上就有毛边，是去背景这一步的问题；绿幕图是干净的，是抠绿这一步的问题。

## 上主播下录影（版面，默认关闭）

> **验证状态**：「上主播下录影」的配音、对嘴、混音流程，作者在 Colab 实测过一次（L4，对嘴 26.5 秒约 39 分钟，整次约 1.5 计算单元）。那次录影几乎没有原声，配音也没有比录影短，所以「录影原声」和「待机循环」还没在 Colab 上触发过（只在作者的电脑上单独测过合成）。**现在这个「切成上下两格」的版面，只在作者的电脑上验证过**：用 notebook 里的代码，在电脑上重新合成并烧字幕（用了那次 Colab 的对嘴片，加一支 1920×1040 的浏览器录屏；还用了仓库示例主播图做成的静态片，加一支 720×1280 的竖屏片，并跑过 ⑥ 只重做字幕）。**还没在 Colab 上实跑过。**

如果你想把主播和一段录影（比如游戏录屏）上下拼成一条竖屏短视频，可以在 ①-2 设置格把「版面」选成「上主播下录影」：

- 成品固定是 **1080×1920（9:16）**，画面分成上下两格直接拼接（中间没有渐变过渡，也没有外框）：
  - **上格 1080×820：主播。** 对嘴画面等比放大到 1080 宽，从「主播上裁」的高度往下取 820 像素。默认让头顶贴近上边缘，身体露到胸口。
  - **下格 1080×1100：放录影。** 程序先按「录影上裁」和「录影下裁」裁掉不属于游戏的部分（比如浏览器地址栏），然后把剩下的高度**整段**放进下格，上下不再裁剪。这样游戏底部的操作栏（调速度、调额度等按钮）就能完整保留，观众听解说时看得清楚。左右方向则按下格的比例（宽度＝剩下的高度 × 1080 ÷ 1100），以「录影左右位置」为中心来截取。
    - 例：1920×1040 的浏览器录屏，上方 84 像素是地址栏 → 「录影上裁」填 8 → 剩下 956 像素高，左右从正中间取 938 像素宽（游戏两侧会带到一点游戏背景）→ 缩放到 1080×1100。
    - 录影比下格还窄时（例如已经裁好的 720×1280 竖屏片）：照高度放满，上下不裁，左右置中。两侧空出来的部分，用同一段录影放大、模糊、压暗来补满。
    - 如果是纯横屏游戏（游戏内容占满整个宽屏），放进下格时左右两边会被裁掉一部分。因为这个版面本来是专门给「游戏在中间、两侧是背景」的录屏以及竖屏录影设计的。
  - **字幕**固定放在上下两格的交界处（y＝820）。
- 主播用原来的背景，不去背景：「去背景」要选「关」（选别的会直接报错）。画面比例建议用默认的 9:16（其他比例也能合成：主播画面会放大到盖满上格，多出来的部分，左右或上下裁掉）。
- 在开始对嘴之前，②-2 会先列出录影的截取范围（例如「左右取 x=490–1428」），方便你提前确认裁切位置对不对。
- **跑完才发现版面要调**（例如主播头顶被切到、游戏没在中间）：不用重跑配音和对嘴。
  1. 修改 ①-2 的版面设置（录影上裁、录影下裁、录影左右位置、主播上裁、补边模糊度、补边亮度、保留录影原声）。
  2. 运行 ①-2。
  3. 只运行 ⑤。它会重新合成，并再下载一次 `talking_avatar_outputs.zip`（用 ①-3 上传的录影、背景音乐，重跑 ①-2 后照样有效）。

  换了背景音乐（在 ①-2 改「背景音乐路径」，或在 ①-3 重新上传）时，先运行 ②-2，再运行 ⑤。换了录影（「录影路径」）要重新点「全部运行」：台词的秒数和对嘴的长度，是照旧录影排的；这时只运行 ⑤，会直接停下来提醒你。这些都要在删除运行时之前做。**这个做法只在作者的电脑上模拟验证过**（按顺序运行 notebook 各格的代码：主播上裁 9→14、录影左右位置 50→45 后，只重跑 ⑤，版面确实跟着改），还没在 Colab 上实际操作过。
- **成品的总长度跟着录影走。**
  - 配音比录影短：对嘴只做到最后一句结束后约 2 秒（这段是静音，可以省计算单元）。之后的主播画面，只拿这段静音画面来回循环（倒放、正放），假装在待机，不会循环到讲话的画面。
  - 配音比录影长：录影停在最后一格，直到配音结束。
- 不内置任何音乐，也不加音效、行动号召（CTA）。

| 栏位（表单上显示的名称） | 默认值 | 说明 |
|---|---|---|
| 版面 | `只有主播` | 选「上主播下录影」，才会用到下面这些设置 |
| 录影路径 | `/content/my_recording.mp4` | 要合成的录影文件：可以在 ①-3 勾选「上传录影」来上传，或者先传到左侧「文件」面板再填路径（录影文件很大时，建议用文件面板上传）。支持 mp4、mov、webm、mkv 等常见格式 |
| 录影上裁 | `0` | 录影顶部要裁掉的比例（%）。只用来去掉不属于游戏的部分，比如浏览器地址栏（1920×1040 的录屏大约填 8%）或手机状态栏。如果下格顶部露出了地址栏就调大；如果游戏画面上方被切掉了就调小 |
| 录影下裁 | `0` | 录影下方裁掉的比例（%）。游戏下方的操作栏不要裁；录屏下方有不属于游戏的东西（例如系统任务栏）时才用 |
| 录影左右位置 | `50` | 游戏在录影里左右的中心位置（%）：50＝正中间；游戏偏左就调小，偏右就调大。取到录影边缘外时，会自动往内挪并提醒你；录影比下格窄时不用 |
| 主播上裁 | `9` | 主播画面上方裁掉的比例（%）：主播画面放大到 1080 宽后，从这个高度往下取 820 像素。默认让一般「人物头在上方」的角色图，头顶贴近上边缘；头顶上方空太多 → 调大（例如 12～14），头顶被切掉 → 调小（0＝从最上面开始取） |

### 台词对时

台词每行开头可以选填开始秒数，让台词对准录影里的画面：

```
大家好，今天来看这一段。
3.0｜注意看，马上要开始了。
14.0｜(兴奋)来了来了！就是这里！
最后结果还不错，我们下次见。
```

- 格式为 `秒数｜台词`，竖线用全角的 `｜` 或半角的 `|` 都可以；语气括号请写在竖线后面。
- 没有写秒数的行，会等上一行念完并空出「句间停顿」的秒数后再开始念（如果第一行没写秒数，就从第 0 秒开始）。
- 两句重叠（指定的时间到了，上一句还没念完）：后一句会往后顺延到上一句念完，并在 ③-1 印出提醒。
- 句子超出录影长度：照常放（这段录影停在最后一格），并印出提醒。
- 配音长度要生成以后才知道，所以实际的时段，以 ③-1 印出的「每句的实际时段」为准。
- 「只有主播」版面也可以写秒数（例如开头先留几秒空白）；不写秒数时，不受影响。

### 声音大小

- 主播的配音声音最大（响度统一调到约 -16 LUFS）。
- 录影原声（勾选了「保留录影原声」且录影有声音时）平时约 -26 LUFS；背景音乐（选填）平时约 -28 LUFS。
- 主播讲话时，录影原声和背景音乐会按台词的时段，自动再压低 12 dB（讲话前 0.15 秒开始压，讲完后 0.4 秒内恢复）。最后再经过限幅器，峰值不超过 -1 dBFS。
- 这些音量参数都写在 ②-2 这一格的开头，一般不用改。

### 字幕和下载

- 字幕沿用上面「字幕」一节的设置（字体、大小、效果、颜色、去逗号句号），时间用排好的实际时段。字幕中心放在两格交界（y＝820），「字幕位置」「字幕边距」不使用。字号较大时，整行往上收，下缘不进入 TikTok 右侧的按钮列（约 x≥894、y≥915）。
- 两句隔得很久时，上一句字幕最多多留 `max(句间停顿, 1)` 秒就消失，不会一直挂着。
- 跑完后照常只自动下载一次 `talking_avatar_outputs.zip`，里面包含：成品视频 `talking_avatar.mp4`（1080×1920）、字幕文件 `talking_avatar.srt`、不带字幕的 `talking_avatar_nosub.mp4`，以及一份只有主播画面的对嘴视频 `talking_avatar_host.mp4`（不带字幕）。
- 成片比较大，⑤ 和 ⑥ 都不在 notebook 里预览（「只有主播」版面照旧预览），请看下载的压缩包里的 `talking_avatar.mp4`。
- ⑥ 只重做字幕照样能用（重烧的是 1080×1920 的合成版）。

## 使用规范

- 只使用 **你本人**、**已取得当事人同意的人**、或 **AI 生成的虚构角色** 的脸和声音。
- **严禁冒充他人**。禁止将本项目用于误导、诈骗、诽谤，或未经同意制作他人的影像与声音。
- Google Colab 的使用条款明文禁止制作深度伪造内容（*creating deepfakes*），详见 [Colab FAQ](https://research.google.com/colaboratory/faq.html)。违规操作可能导致你的账号受限。
- 公开发布成品时，建议主动标明「AI 生成」。

| 去背景：绿幕 ⑤-2 | 约 40 秒 |
| 去背景：逐帧 ⑤-2 | 354 帧耗时约 92 秒（整格跑完约 141 秒） |
| ⑥ 只重做字幕 | 每次约 2～5 秒 |

16:9、4:5、3:4 这三种画面比例的耗时还没有实测过。

对嘴耗时大致跟段数成正比：第 1 段 81 帧（约 3.24 秒），之后每段多 72 帧（约 2.88 秒）。作者实测过最长的成品是 27.96 秒（10 段、699 帧，对嘴约 39.4 分钟，L4 全程没断线；2026-11-07 饶舌口播，用同一套对嘴流程），更长的台词，耗时和运行内存够不够，没验证过。

**跑完一定要「断开连接并删除运行时」，闲置时也会扣计算单元。**

## 常见问题

**明明选了 L4，连上却变成了 T4？**
浏览器同时登录多个 Google 账号时，Colab 默认用**第一个**账号。那个账号的计算单元是 0 时，会被降成 T4。请到 <https://colab.research.google.com/signup> 确认当前账号的余额。T4（15GB 显存）没测试过，很可能显存不够，或者非常慢。

**报错 `OutOfMemory` 或 `OOM`（显存不够）怎么办？**
点「代码执行程序 → 重启会话」→ 在 ①-2 设置格勾选「省显存模式」→ 点「全部运行」。已装好的 ComfyUI 和已下载的模型会跳过，配音会重新生成。

**报错「ComfyUI 意外停止了」怎么办？**
多半是运行内存或显存不够，台词越长越容易遇到。先把台词缩短，或者勾选「省显存模式」。详细原因，看左侧文件面板里的 `/content/comfyui.log`。

**声音不满意？**
先在「声音包」试听，「声音」换一把重跑。都不合适的话，选「自定义（按声音描述）」，改「声音描述」或换「随机种子」重跑（设计声音本来就每次都不同）。

**饶舌的 ③-1 出现红色框「饶舌卡在……」？**
照红框里写的做（多半是「重新运行本格」，装好、下载好的会接着用）。还是一样的话，截图红框和下面的细节，发给作者。

**饶舌有几句没有字幕？**
那几句 AI 没唱出来或念糊了（③-1 会列出「⚠ 只听到 x/y 个字」）。换一个「饶舌随机号」重生，或把歌词删短一点。

**字幕和说话的声音有点对不上？**
字幕时间是按每句配音长度推算的。一句被切成几段时，每段的时间按字数比例估，念得快慢不均时会有些偏差。把长句拆短（一行一句），最有效。

**想换字幕样式？**
不用重跑：改 ①-2 的字幕设置 → 运行 ①-2 → 运行 ⑥（见「字幕 → 只重做字幕」）。删除运行时后，就不能重做了。

**去背景选了「绿幕」，结果人物边缘泛绿，或者有一块背景没抠掉？**
作者实测过绿幕（1:1，一次跑通）：对嘴后，绿色背景没有明显偏色，取到的抠除色接近纯绿；换到绿底前已经估计过前景色，发丝外围的深色描边实测消失了。逆光、头发蓬乱、飞毛多的图，发丝外围仍可能留一圈淡淡的毛边，见下一条「去背景后头发外围有一圈毛边？」。
绿幕路线出问题（背景扣不干净、边缘带绿）时，在 ①-2 把「去背景」改成「逐帧」，然后**重新点「全部运行」**。不要只运行 ⑤-2：拿绿底的成品再跑逐帧，发丝和缝隙的边缘，实测会带绿。

**去背景后头发外围有一圈毛边？**
多半是角色图本身的问题：逆光（人物背后有强光、发丝边缘发亮），或头发蓬乱、飞毛多的图，去背景后发丝外围容易留下一圈毛边（原图背景的颜色混在发丝里，换参数也去不干净）。主播图尽量选不逆光、头发整齐的；有这种图时，建议换图。

**透明 WebM 视频打开后背景是黑色的？**
不是所有播放器都支持透明 WebM。要放进支持透明视频的剪辑或合成软件里，才看得到透明效果。

**跑完后浏览器没有自动弹出下载？**
一次只会自动下载一次（文件多时，打包成一个压缩包），但 Chrome 还是可能拦截。地址栏右边出现下载被拦截的图标时，点它选允许；或者到左侧「文件」面板的 `output` 文件夹，右键文件 →「下载」。

**用完了怎么关？**
点「代码执行程序 → 断开连接并删除运行时」。第一次点，可能会先弹出警告；确认后，要再点一次删除。

## 给开发者的技术说明

以下是工具和实现细节。只想用的话，可以跳过这一节。

### 流程图

```
① 台词 ＋ ①-1 选模板、上传录影和背景音乐（选填）
＋ 进阶：①-2 设置（声音、角色图、比例、去背景、版面、字幕）＋ ①-3 上传文件（选填）＋ ①-4 存成模板（选填）
        │
        ▼
③ 配音：VoxCPM2
   声音包参考音（默认）；或音色设计（用文字描述造一把声音，只做一次，存成参考音）
   → 逐句可控克隆（每句 ≤80 字，超过自动切开）
   → 句间插入停顿，接成一条音轨 voice.wav（同时记下每句的起止时间＝字幕时间轴）
   → 删除模型、释放显存
③-2 字幕准备：下载字体、检查缺字（有问题在对嘴之前就报错）
        │
        ▼
④ 对嘴：ComfyUI v0.43.0 + InfiniteTalk（Wan2.1 I2V 14B 480P）
   角色图按 ASPECT／CROP_POS 裁切缩放（默认 9:16 的 480×832）
   （BG_REMOVE＝绿幕时：先用 BiRefNet 把背景换成纯绿（发丝先做前景色估计），释放显存后才启动 ComfyUI）
   → 每段 81 帧、重叠 9 帧往后延伸 → 长度跟配音走
        │
        ▼
⑤ 合成：画面 + 原始配音（AAC）→（版面选「上主播下录影」时：和录影合成 1080×1920、混音）→ 烧进字幕（ASS＋ffmpeg）→ /content/output/talking_avatar.mp4 ＋ talking_avatar.srt ＋ 不带字幕的 talking_avatar_nosub.mp4 → 去背景关闭时在这里打包下载
        │
        ▼
⑤-2 去背景输出（BG_REMOVE 不是「关」时）：绿幕＝ffmpeg chromakey＋despill；逐帧＝每帧 BiRefNet
   → talking_avatar_alpha.webm（VP9＋透明通道，不烧字幕）＋ 绿幕时的绿幕图 input_greenscreen.png
   → 连同 ⑤ 的文件打包成 talking_avatar_outputs.zip 下载（一次流程只自动下载一次）
        │
        ▼
⑥ 只重做字幕（换字幕样式时才用；「全部运行」时会自动跳过）
```

（② 是环境检查：显示 GPU 型号、获取示例文件、确认输入文件存在。）

### 其他实现细节

- `talking_avatar_alpha.webm`：采用 VP9 视频编码＋透明通道（`yuva420p`）＋原始配音（Opus 音频编码）。
- 绿幕路线：先用 ffmpeg 的 `chromakey` 滤镜抠掉绿色背景，再用 `despill` 滤镜消除人物边缘泛出的绿光。相关抠色参数（`KEY_SIMILARITY`、`KEY_BLEND`、`DESPILL_MIX`、`DESPILL_BLUE`）定义在 ⑤-2 格的开头。
- 音量响度参数定义在 ②-2 格的开头：包括 `VOICE_LUFS`、`REC_LUFS`、`BGM_LUFS`、`DUCK_DB` 等。
- 勾选「省显存模式」（`LOW_VRAM = True`）时，ComfyUI 会加上 `--novram` 参数启动。
- 字幕的字号、边距、一行放几个字，按 notebook 里的 `WIDTH`、`HEIGHT` 推算。
- 「声音克隆」里，参考录音文字对应参数 `prompt_text`（VoxCPM 官方不允许它和语气指令一起用）。
- ComfyUI 只监听 127.0.0.1，不开网页界面。
