# 新手操作手册

这份手册写给**完全没用过 Colab、也不会写代码**的人。

怎么用：每一步只做一个动作。做完后，对照一下「做对了会看到」。对上了，再做下一步。对不上，先看最后面的「常见问题」。

整个流程是：准备账号 → 打开笔记本 → 设置 → 点「全部运行」→ 等待 → 下载视频 → 删除运行时。

先认识四个词：

- **笔记本（notebook）**：网页上的程序文件，由一格一格组成。灰底的格子可以运行。我们用的是 `talking_avatar.ipynb`。
- **GPU（显卡）**：专门做大量计算的硬件。这里用的是 Google 机房里的显卡，你的电脑不需要有。
- **运行时（runtime）**：Google 临时借给你的一台云端电脑，笔记本在它上面运行。用完一定要删掉，不然会一直扣费。
- **计算单元（compute units）**：Colab 的计费点数。使用 L4 GPU 会按时间扣除。

> **只想生饶舌歌（mp3），不做视频？** 用另一本 `rap_song.ipynb`，直接跳到最后面的「只生成饶舌歌（不做视频）」那一节。

## 准备篇

### 第 1 步：准备 Google 账号

**要做的**：准备一个有计算单元的 Google 账号（也就是 Gmail 账号）。

浏览器里登录了多个账号时，Colab 默认用第一个。最稳妥的做法：开一个“无痕／隐私窗口”，只登录要用的这个账号，再打开 <https://colab.research.google.com>。

**做对了会看到**：点右上角头像，菜单最上面显示的是你要用的账号。

![Colab 右上角头像（右上红框）与账号菜单；账号信息已涂掉](images/02-account-menu.png)

### 第 2 步：确认账号里有计算单元

这个项目要用 **L4 GPU**，而 L4 要用计算单元。计算单元可以在 Colab 购买，也有 Google AI Pro 等方案会附送。

**要做的**：打开 <https://colab.research.google.com/signup>。

**做对了会看到**：「Pay As You Go」下面写着“您目前有 N 个计算单元。”。如果余额是 0，选 L4 会失败，或者被降成 T4。

![signup 页面：红框处是计算单元余额](images/01-signup-compute-units.png)

## 打开并设置 Colab

### 第 3 步：打开笔记本

**要做的**：打开本项目的 GitHub 页面（README 最上方），点 **Open in Colab** 徽章。

**做对了会看到**：页面标题是 `talking_avatar.ipynb`，第一格的标题是“会说话的主播……”。

![笔记本首屏：红框是第一格的标题](images/03-notebook-first-screen.png)

### 第 4 步：选择 L4 GPU

**要做的**：

1. 点顶部菜单的「代码执行程序 → 更改运行时类型」。
2. “硬件加速器”选 **L4 GPU**。通常已经选好了，确认一下就行。
3. 点「保存」。

**做对了会看到**：点右上角的“连接 L4”连接后，右下角显示 `L4（Python 3）`。

![更改运行时类型窗口：L4 GPU 被选中，再点保存](images/05-runtime-type-l4.png)

### 第 5 步：看你有没有模板

模板是一组存好的设置，包括角色图、声音、字幕、版面。存在你自己的 Google 云端硬盘里。同一个角色要做很多支片时，用模板最省事。

- **之前存过模板** → 走「路线 A」，从第 6 步开始。
- **没有模板，或者不想用模板** → 走「路线 B」，从第 8 步开始。
- **想把现在的设置存成模板** → 先照路线 B 做完，再看后面的「存成模板」。

## 路线 B：自己设置

### 第 8 步：换台词

**要做的**：和第 6 步一样。找到 **① 台词** 下面的格子，把三个引号之间的句子换成你的台词。一行写一句，超过 80 字会被自动切开。如果不想改，可以跳过，程序会使用示例台词。

**做对了会看到**：前后的三个引号 `"""` 还在，中间是你的句子。

### 第 9 步：选声音

**先展开「进阶」那一段**：点「进阶：建立／修改模板」标题左边的箭头，把它展开。因为 **①-2 设置** 在这一段里，而这一段默认是收起来的。（如果打开时已经展开，直接往下找就行。）

**要做的**：

1. 在 **①-2 设置** 这一格（只显示表单，代码是收起来的），找到「声音」那一段。
2. 点「声音」下拉菜单，选一个声音。默认是“新闻女主播”。
3. 想先试听：10 把声音都可以试听。到 README 的“声音包”一节，每把声音后面都有「试听」链接。

如果不想改，可以跳过。

**做对了会看到**：表单里的「声音」显示为你选的声音。

想做**饶舌口播**（AI 自己配 beat 来饶舌）：「声音」选“饶舌（AI 生成）”，然后看下面的「饶舌模式」一节。

如果你想用文字描述，自己生成一个声音：

1. 在「声音」里选“自定义（按声音描述）”。
2. 把「声音描述」文本框里的话，换成你想要的声音特征（性别、年龄、音色、语速、语气）。

示例：

- `年轻女性，声音清亮自然，语速中等，语气亲切平稳，像新闻主播在播报`
- `中年男性，嗓音低沉温和，语速偏慢，语气沉稳可靠，像纪录片旁白`

### 第 10 步：（选做）字幕设置

成品默认带字幕：思源黑体、单层黑色描边、每段字幕淡入。字幕文字就是你的台词，不会有错字。不想改的话，可以跳过。

**要做的**：如果想换样式，在 ①-2 设置格表单的「字幕」那一段修改：

- 「显示字幕」：开关。取消勾选，就是不要字幕。
- 「字幕字体」：选择字体。
- 「字幕大小」：拖动滑块，调整字号大小。
- 「字幕效果」：选择字幕出现的方式。
- 「字幕位置」：选择字幕在画面中的位置。
- 「字幕边距」：离边缘多远。
- 「字幕描边」：调整文字黑边的粗细。
- 「字幕颜色」「描边颜色」：设置颜色。要写成 `#FFFFFF` 这种格式。

**做对了会看到**：表单里的选项变成你设置的值。

跑完以后还想换字幕，不用重跑，见后面的「换字幕样式」。

### 第 11 步：（选做）画面比例与去背景

如果不想改，可以跳过。默认是 9:16 竖屏（480×832），不去背景。

**要做的**：在 ①-2 设置格的表单里修改：

- 「画面比例」：可选 9:16 竖屏、16:9 横屏、1:1 方形、4:5、3:4。
- 「裁切位置」：当角色图的比例和画面不一致时，决定裁掉哪一边。默认是「偏上」，这样会保留人物头部。
- 「去背景」：如果想要透明背景的视频（方便之后放进别的视频模板里用），请选「绿幕（推荐）」或「逐帧」。选「绿幕」时，`talking_avatar.mp4` 的背景会变成绿色；透明背景的版本是另外下载的 `talking_avatar_alpha.webm`（不带字幕）。

想做“上主播下录影”的版面，做法比较复杂，请看 README 的“上主播下录影”一节。

**做对了会看到**：运行 ①-2 这一格后，会出现一个绿色框，里面有类似这样的一行：`✅ 设置已读取：画面 480x832，裁切「偏上（保留头部）」，去背景「关」，版面「只有主播」`。

各个选项的详细说明，请看 README 的“画面比例”和“去背景”两节。

### 第 12 步：（选做）上传自己的角色图

如果不换图，可以跳过。

**要做的**（有两种方法，任选一种）：

- **方法一（简单）**：
  1. 在 **①-3 上传文件** 这一格，勾选「上传角色图」。
  2. 等第 14 步点「全部运行」并跑到 ①-3 时，这一格下面会出现「选择文件」按钮。点它，选择**一张**图片。
  3. 用方法一不用做第 13 步。
- **方法二**：
  1. 点左侧的**文件夹图标**（「文件」面板）。
  2. 再点上方的“上传”图标，选图片。
  3. 如果没有文件列表，先点右上角的「连接」。
  4. 然后做第 13 步。

**做对了会看到**：

- 方法一：①-3 这一格显示绿色框，写着「角色图：已上传 /content/你的图.png……」。
- 方法二：左侧文件列表里出现你的图片（在 `/content/` 目录下）。如果弹出“文件会被删除”的警告，点「确定」。

录影、背景音乐、字体文件、参考录音，也一样可以在 ①-3 勾选上传。录影很大时，建议用方法二，再到 ①-2 填「录影路径」。上传过的文件会一直接着用，之后重跑 ①-2 也不会丢。上传完，①-3 的勾可以取消。

图片的要求：

- 比例接近你选的画面比例（默认是**竖图**）。
- 人物**正脸**看镜头，**闭着嘴**。
- **脸够大**：拍到上半身即可，不要用全身照。
- **手不要入镜**。
- 文件名用英文或数字（例如 `me.png`）。
- 只能使用你本人的、已取得当事人同意的，或 AI 生成的虚构人物照片。

**要做的**：在 ①-2 设置格「角色图」那一段，找到「角色图路径」输入框。把 `examples/host.png` 改成 `/content/你的图.png`（文件名的大小写要一样）。

## 饶舌模式（选做）

做饶舌口播时才看这一节。AI 会照你写的歌词，自己配上 beat 来饶舌，再让角色跟着饶舌开口。成品的声音是带 beat 的完整版。

### 饶舌 1：选饶舌

**要做的**：

1. 展开「进阶：建立／修改模板」，找到 **①-2 设置**。
2. 「声音」下拉菜单选“饶舌（AI 生成）”。
3. 「饶舌声线」选“女声”或“男声”（跟角色图配一下）。

如果开着「开启声音克隆」，要先取消勾选，不然会报错停下。用模板的话，模板里存了饶舌，就不用做这一步。

**做对了会看到**：表单里的「声音」显示“饶舌（AI 生成）”。

### 饶舌 2：写歌词

**要做的**：在 **① 台词** 的三个引号之间，换成你的歌词，一行一句。

歌词写多长比较好：**每句 8～10 字、10 句以内。** 写太多，AI 会吞字（把几句压成一句，或整句不唱）。写多了也照样会生成，③-1 会出现黄色的提醒，告诉你哪里太多。

中英混写会自动处理；英文还是没唱出来的话，可以把英文写成中文谐音（例如 PG 写成「皮鸡」、Yeah 写成「耶」）。

最长可以做到 3 分半；歌越长，AI 越容易吞字，对嘴也越久（3 分半的歌对嘴要好几个小时，会用掉很多计算单元），建议先只生成试听。

**做对了会看到**：三个引号还在，中间一行一句歌词。

### 饶舌 3：（推荐）先试听，再对嘴

对嘴要等 30～40 分钟。先听饶舌满不满意，比较省时间。

**要做的**：

1. 往下找到 **③-1 配音** 这一格，勾选「先试听再对嘴」。
2. 点「代码执行程序 → 全部运行」。

**做对了会看到**：③-1 跑完后，停在这一格，出现蓝色的「⏸ 已暂停」框（这不是出错）。上面有两个音频条：第一个是带 beat 的完整版，第二个只有人声。还会列出每句歌词有没有唱出来（✅＝有，⚠＝没唱清楚，这句不会有字幕）。

- **不满意**：把「饶舌随机号」换一个数字（例如 2025 改成 7），再点 ③-1 这一格左边的 ▶。会重新生成一版，再听一次。数字本身没有好坏，只是换一版。
- **满意了**：取消勾选「先试听再对嘴」，再点「代码执行程序 → 全部运行」。这一版会直接沿用（不会重新生成），接着做对嘴和合成。如果 ①-1 或 ①-3 还勾着上传，会再跳出「选择文件」按钮，这时点取消，就会沿用之前上传的文件。

不想先听的话，这一步跳过，「全部运行」会一路做到底。

### 饶舌 4：等待

- ③-1 第一次要装工具、下载模型，作者估计约 5～8 分钟（还没实测）。换数字重生，估计约 2～3 分钟。这段时间画面不会动，是正常的。
- 对嘴跟一般口播一样，按长度算：28 秒的饶舌，作者实测约 39 分钟。

**做对了会看到**：和一般口播一样，最后下载 `talking_avatar_outputs.zip`。成品的声音是带 beat 的完整版，字幕是你写的歌词。

### 饶舌出问题时

- ③-1 出现**红色框**「饶舌卡在……」：照框里写的做，多半是「重新运行本格」（点 ③-1 左边的 ▶）。装好、下载好的部分会接着用。还是一样的话，**截图红框和下面的细节，发给作者**。
- 出现黄色框「字幕对齐……改成按字数平均分配」：流程会照常跑完，只是字幕时间可能不准。介意的话，跑完后到 ①-2 取消勾选「显示字幕」，运行 ①-2，再运行 ⑥，拿没有字幕的版本。截图发给作者。
- 有几句没有字幕：那几句 AI 没唱出来或念糊了。换一个「饶舌随机号」重生，或把歌词删短。

## 运行、等待、下载

无论走路线 A 还是路线 B，都从这里继续。

### 第 14 步：全部运行

**要做的**：点顶部菜单的「代码执行程序 → 全部运行」。

**做对了会看到**：正在运行的格子左边会转圈，跑完后变成绿勾，格子下面出现绿色的「✅」框。

- ①、①-2、② 这几格几秒钟就会跑完。
- 如果第 12 步用了方法一，程序会停在 ①-3，等你选文件。
- ③-1 这一格刚跑时，会出现黄色的「⏳ 进行中」框，要转好几分钟，这是正常的。

### 第 15 步：处理安全警告

**要做的**：如果弹出“警告：此笔记本不是由 Google 创作”，点「**仍然运行**」。如果没弹出来，直接看下一步。

**做对了会看到**：格子继续往下运行。如果过了半分钟都没有格子在转圈，请再点一次「全部运行」。

<!-- 截图：“此笔记本不是由 Google 创作”警告窗口，标出“仍然运行” -->

### 第 16 步：等待

**要做的**：保持这个网页打开，耐心等待。

**做对了会看到**：

- ② 这一格会打印 `GPU：NVIDIA L4，显存 22.x GiB`。如果出现 `⚠ 警告`，请看后面的「常见问题」。
- ③ 这一格跑完后，会出现可以试听的音频播放器。
- ④-5 这一格耗时最长。开头的黄色框会写这次分成几段处理，之后每 30 秒打印一行 `[ xxx 秒] ...`。进度条走完 6 步代表完成一段，之后会回到 `0/6` 继续做下一段，这是正常的。

耗时参考：示例台词（配音长 10.88 秒）全部跑完大约要 22 分钟，其中对嘴型大约要 16 分钟。台词越长，耗时越久。

![④-5 格运行中：每 30 秒一行进度（截图待补拍）](images/12-lipsync-progress.png)

### 第 17 步：下载成品

**要做的**：等 ⑤ 这一格出现绿色的「✅ 合成完成」框。如果开启了去背景，还要再等 ⑤-2 这一格出现「✅ 去背景完成」框。

浏览器只会自动下载一个文件：`talking_avatar_outputs.zip`。解压后有：

- `talking_avatar.mp4`：成品视频。
- `talking_avatar.srt`：字幕文件。
- `talking_avatar_nosub.mp4`：不带字幕的视频。
- 开了去背景时，还有 `talking_avatar_alpha.webm`；选了「绿幕」的话，还有绿幕图 `input_greenscreen.png`。

### 换字幕样式（可跳过）

**要做的**：

1. 回到 ①-2 设置格，修改「字幕」那一段的选项（见第 10 步）。

3. 往下找到标题是 **⑥ 只重做字幕** 的格子，点它左边的 ▶ 按钮运行。

如果 ⑥ 这一格报错，提示“缺少前面几格准备好的功能”，请依次运行 ①、①-2、②、②-2、③-2 这五格，然后再运行 ⑥。注意**不要**运行 ③-1，否则会重新配音。

### 存成模板，下次直接用（可跳过）

同一个角色（同一张图、同一把声音、同样的字幕和版面）要做很多支片时，可以存成模板。以后每支片，只要换台词（和录影）。

**要做的**：

1. 找到「进阶」那一段里的 **①-4 存成模板** 这一格。

   - 已经跑完才想存：填好名称后，点 ①-4 这一格左边的 ▶ 运行它（声音会一起存）。
4. 存好以后，记得把「新模板名称」清空。不然之后每次点「全部运行」，都会再重复存一次。

## 只生成饶舌歌（不做视频）

只要一首饶舌歌（mp3）、不做视频时，用另一本笔记本 `rap_song.ipynb`。整本只有五格，比做视频那本简单很多。账号和计算单元的准备，跟第 1、2 步一样。

### 饶舌歌 1：打开笔记本，选 L4

**要做的**：

1. 打开本项目的 GitHub 页面，在 README 最上面「只想生饶舌歌（不做视频）」那一行，点 **Open in Colab** 徽章。
2. 照第 4 步，选 L4 GPU，点「保存」。

**做对了会看到**：页面标题是 `rap_song.ipynb`，第一格的标题是“饶舌歌生成……”。

### 饶舌歌 2：填三项

**要做的**：先在「歌词」那一格贴歌词，再在「① 选音色、随机号」选音色：

1. **歌词**：找到第一行是 `%%writefile` 的那一格。第一行不要动，把下面的示范歌词换成你的歌词，一行一句，不需要任何引号。每句 8～10 字最稳，字越多越容易吞字。
2. **音色**：在「① 选音色、随机号」下拉菜单选一个。不知道选哪个，先用默认的“女·清亮”。音色是用文字提示 AI，效果有时明显有时不明显。
3. **饶舌随机号**：第一次先不用改。

中英混写会自动处理；英文还是没唱出来的话，可以把英文写成中文谐音（例如 PG 写成「皮鸡」、Yeah 写成「耶」）。

歌有多长：约＝字数×0.23 秒＋5 秒（例如 72 字约 22 秒），最长 3 分半。写超过了，会出现黄色提醒，照样会生成。

**做对了会看到**：歌词那一格第一行 `%%writefile` 还在，下面是一行一句的歌词；表单上显示你选的音色。

### 饶舌歌 3：全部运行，等待

**要做的**：点「代码执行程序 → 全部运行」。弹出「此笔记本不是由 Google 创作」时，点「仍然运行」。

第一次要装工具、下载约 8GB 模型，作者估计约 2～4 分钟（还没整本实测）。这段时间画面不会动，是正常的。

**做对了会看到**：「② 生成饶舌」下面出现播放条和绿色的「✅ 生成完成」框，浏览器自动下载一个像 `rap_2025_f_bright.mp3` 这样的文件。

没有自动下载：左边文件面板 → `rap_song` → 在 mp3 上按右键 → 下载。

### 饶舌歌 4：不喜欢，就换个号再跑

随机号像抽卡：同一份歌词换个号，节奏和念法就不同。没办法先知道哪个号好听，只能生成出来听。

**要做的**：在 ① 把「饶舌随机号」换一个数字（例如 2025 改成 7），或者换一个音色，再点「代码执行程序 → 全部运行」。

**做对了会看到**：这次不会再装工具、下载模型。又下载一个新的 mp3，旧的不会被盖掉。

### 饶舌歌 5：删除运行时（一定要做）

**要做的**：跟第 18 步一样，点「代码执行程序 → 断开连接并删除运行时」。不删的话，会一直扣计算单元。

出现红色框「饶舌卡在……」：照框里写的做。还是一样的话，截图红框和下面的细节，发给作者。

## 常见问题

**② 这一格出现警告，GPU 显示 T4，不是 L4？**
账号没有计算单元，或余额是 0。回到第 1、2 步检查。改好以后，重做第 4 步，再点「全部运行」。T4 没测试过，很可能失败。

**报错里有 `OutOfMemory` 或 `OOM`（显存不够）？**
1. 点顶部菜单的「代码执行程序 → 重启会话」。
2. 在 ①-2 设置格最下面的「进阶：显存」里，勾选「省显存模式」。
3. 点「代码执行程序 → 全部运行」。

会变慢，但比较稳。

**中途断线了？**
分页关太久、电脑睡眠、断网，都会让运行时断开，云端的文件也会消失。请重新打开笔记本，从第 4 步再来一遍。

**浏览器没有自动下载？**
Chrome 可能拦截了下载。地址栏右边出现下载被拦截的图标时，点它选“允许”。或者到左侧「文件」面板 → `output` 文件夹 → 右键文件 →「下载」。

**成品没有声音？**
先听 ③ 这一格的音频条。有声音的话，换一个播放器（浏览器或 VLC）打开 mp4。没有声音的话，检查台词是不是空的。

**嘴型对不上？**
检查角色图：要正脸、闭嘴、脸够大、嘴没被挡住。长句容易对不准，把长句拆短。

**声音不喜欢？**
把「声音」换一把（先到 README 的“声音包”试听），再点「全部运行」。用“自定义”时，可以换「随机种子」的数字（例如 42 改成 7），或者改「声音描述」。

**饶舌的 ③-1 出现红色框？**
照红框里写的做（多半是再点一次 ③-1 左边的 ▶）。还是一样，截图发给作者。详见「饶舌模式 → 饶舌出问题时」。

**字幕和声音有点对不上？**
字幕时间是按每句配音的长度估的，长句被切成几段时，会有些偏差。把台词里的长句拆短（一行写一句）。

**字幕出现方框，或字体不一样？**
③-2 这一格会列出字体缺的字。到 ①-2，把「字幕字体」换成“思源黑体（粗）”（它收的字最全），再照“换字幕样式”重做。

**去背景选了「绿幕」，边缘有绿边，或背景没抠干净？**
到 ①-2，把「去背景」改成“逐帧”，再点「全部运行」。不想重跑对嘴的话：改好以后，运行 ①-2，再只运行 ⑤-2（发丝边缘可能还带一点绿）。

**透明 WebM 打开是黑底？**
有些播放器不支持透明 WebM。要放进支持透明视频的剪辑或合成软件里，才看得到透明效果。

**我想用自己的声音？**
可以，但只能用你本人的录音，或已取得当事人同意的录音。做法见 README 的“声音克隆”一节。要在 ①-2 勾选「确认已获同意」，不然笔记本会直接停止。参考录音可以在 ①-3 勾「上传参考录音」上传。
