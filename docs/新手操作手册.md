# 新手操作手册

写给**完全没用过 Colab、不会写程序**的人。每一节只做**一个动作**，做完对照「做对了会看到什么」，确认无误再往下一节。

先认识 4 个词（后面会反复出现）：

- **notebook（笔记本）**：一个网页上的“程序文件”，由一格一格的内容组成。灰底的格子是“代码格”，可以运行；白底的是说明文字。本项目就是一个 notebook：`talking_avatar.ipynb`。
- **GPU（显卡）**：专门做大量计算的硬件。生成声音和视频都要靠它，你的电脑不需要有，用的是 Google 机房里的。
- **运行时（runtime）**：Google 临时借给你的一台云端电脑（带 GPU）。notebook 就是在这台电脑上运行的。用完要删掉，否则会继续计费。
- **计算单元（compute units，也有人叫“运算单元”）**：Colab 的计费点数。使用 L4 这种 GPU 会按时间扣点数。

---

## 准备篇

### 第 1 步：准备一个 Google 账号

**要做的**：确认你有一个可以登录的 Google 账号（Gmail 账号就是）。

**做对了会看到**：在浏览器打开 <https://accounts.google.com> 能看到自己的账号头像和名称。

### 第 2 步：确认账号里有计算单元

本项目需要 **L4 GPU**，L4 要用**计算单元**。计算单元可以在 Colab 付费购买，或由 Google AI Pro 等方案附送；价格与方案以官方页面为准。

**要做的**：用浏览器打开 <https://colab.research.google.com/signup>。

**做对了会看到**：页面显示当前账号的方案，以及可用的计算单元余额（页面文字以实际显示为准）。余额是 0 的话，后面选 L4 会失败或被降成 T4。

<!-- 截图：colab.research.google.com/signup 页面，标出“计算单元余额”的位置 -->

### 第 3 步：确认 Colab 用的是对的账号

**要做的**：如果你的浏览器同时登录了多个 Google 账号，检查右上角头像。Colab 默认用浏览器里的**第一个**账号。

**做对了会看到**：第 2 步页面右上角的头像，就是有计算单元的那个账号。如果不是：最简单的做法是开一个“无痕／隐私窗口”，只登录有计算单元的那个账号，后面全部在这个窗口里操作。

<!-- 截图：Colab 右上角账号头像与切换账号的菜单 -->

## 开始运行

### 第 4 步：打开 notebook

**要做的**：在本项目的 GitHub 页面（README 最上方）点 **Open in Colab** 徽章。

**做对了会看到**：浏览器打开 Colab 页面，标题是 `talking_avatar.ipynb`，第一格是说明文字“会说话的主播：一张角色图 + 一段文稿 → 口播视频”。

<!-- 截图：用 Open in Colab 打开后的 notebook 首屏 -->

### 第 5 步：选择 L4 GPU

**要做的**：点顶部菜单「代码执行程序 → 更改运行时类型」（英文界面：Runtime → Change runtime type）。也可以用「修改 → 笔记本设置」（英文界面：Edit → Notebook settings），两个入口是同一个设置窗口。在“硬件加速器”里选 **L4 GPU**，点「保存」。

**做对了会看到**：窗口关闭；右上角显示“已连接”或资源指示（RAM／磁盘），把鼠标移上去能看到 GPU 类型。

<!-- 截图：更改运行时类型窗口，L4 GPU 被选中 -->

### 第 6 步：改文稿

**要做的**：找到标题为 `# ① 设置（只需要改这一格）` 的代码格，把 `SCRIPT = """` 和下一个 `"""` 之间的文字换成你自己的文稿。**一行一句**，每句不要太长（超过 80 字会被自动切开）。

**做对了会看到**：三个引号 `"""` 还在原位，中间是你的句子。不想改的话可以跳过这一步，直接用示例文稿。

小技巧：句首可以用括号写语气，例如：

```
(轻松地)大家好，今天聊一个小工具。
(放慢语速，认真地)第一步，先准备一张图。
```

<!-- 截图：① 设置格，标出 SCRIPT 的位置 -->

### 第 7 步：改音色描述

**要做的**：把 `VOICE_DESC = "..."` 引号里的文字换成你想要的声音描述（性别、年龄、音色、语速、语气）。

**做对了会看到**：引号还在，中间是你的描述。示例：

- `年轻女性，声音清亮自然，语速中等，语气亲切平稳，像新闻主播在播报`
- `中年男性，嗓音低沉温和，语速偏慢，语气沉稳可靠，像纪录片旁白`
- `二十多岁的男生，声音明亮有活力，语速稍快，语气轻松，像在和朋友聊天`

不满意可以之后换 `SEED` 的数字再跑一次，同样的描述也会生成不同的声音。

### 第 8 步：上传自己的角色图（不换图可跳过）

**要做的**：点 Colab 左侧的**文件夹图标**（「文件」面板），再点面板上方的“上传”图标，选你电脑里的图片。

**做对了会看到**：文件列表里出现你的图片（它在 `/content/` 文件夹里）。Colab 可能弹出提示“上传的文件会在运行时回收时删除”，点确定即可。

图片要求：

- **竖图**（高比宽长），人物**正面**看镜头；
- **闭着嘴**；
- **脸够大**（上半身入镜就好，不要全身照）；
- **手不要入镜**；
- 只能用你本人、已取得同意的人、或 AI 生成的虚构人物。

文件名建议用英文或数字（例如 `me.png`）。

<!-- 截图：左侧文件面板与上传按钮 -->

### 第 9 步：把 IMAGE_PATH 改成你的图

**要做的**：在 ① 设置格里，把 `IMAGE_PATH = "examples/host.png"` 改成 `IMAGE_PATH = "/content/你的图.png"`（换成实际文件名，大小写要一致）。

**做对了会看到**：`IMAGE_PATH = "/content/me.png"` 这样的一行。拿不准文件名时，可以在文件面板里右键图片 →「复制路径」再粘贴进引号里。

### 第 10 步：全部运行

**要做的**：点顶部菜单「代码执行程序 → 全部运行」（英文界面：Runtime → Run all）。

**做对了会看到**：第一个代码格左边的按钮变成转圈的图标，表示正在运行。

### 第 11 步：处理安全警告

**要做的**：弹出“警告：此笔记本不是由 Google 创作”的窗口时，点「**仍然运行**」（英文界面：Run anyway）。

**做对了会看到**：窗口关闭，代码格继续一格一格运行。如果过了半分钟还没有任何格在转圈，再点一次「全部运行」。

<!-- 截图：“此笔记本不是由 Google 创作”警告窗口，标出“仍然运行” -->

### 第 12 步：等待并查看进度

**要做的**：保持这个浏览器分页开着，等待。不需要做任何操作。

**做对了会看到**：

- ② 格打印 `GPU：NVIDIA L4，显存 22.x GiB`（如果出现 `⚠ 警告`，看下方“常见问题”）。
- ③ 格逐句打印配音进度，跑完会出现一个可以播放的音频条，可以先试听声音。
- ④-5 格每 30 秒打印一行 `[ xxx 秒] ...` 进度，这是最久的一步。

要等多久：示例文稿（约 10 秒）按作者实测换算估计约 25 分钟（**估算，未实测**）；作者实测 21.5 秒的成品，光对嘴就约 36 分钟。文稿越长越久。

<!-- 截图：④-5 格运行中打印进度的样子 -->

### 第 13 步：下载成品

**要做的**：等最后的 ⑤ 格打印出 `====` 框。浏览器会自动下载 `talking_avatar.mp4`；如果浏览器问“是否允许下载”，点允许。

**做对了会看到**：浏览器的下载文件夹里有 `talking_avatar.mp4`，⑤ 格下方也能直接播放视频。没自动下载的话：左侧文件面板 → `output` 文件夹 → 右键 `talking_avatar.mp4` →「下载」。

<!-- 截图：⑤ 格的 ==== 框与视频预览 -->

### 第 14 步：删除运行时（一定要做）

**要做的**：点顶部菜单「代码执行程序 → 断开连接并删除运行时」（英文界面：Runtime → Disconnect and delete runtime）。

**做对了会看到**：右上角变回“连接”按钮。**注意：第一次点可能先弹出警告窗口，按确定后，要再点一次「断开连接并删除运行时」才真正删除。** 不删的话，就算你什么都不做，也会继续扣计算单元。

<!-- 截图：代码执行程序菜单中的“断开连接并删除运行时” -->

## 常见问题

**② 格出现警告，GPU 显示 T4，不是 L4？**
通常是 Colab 用了没有计算单元的账号，或账号余额是 0，于是被降成 T4。回到第 2、3 步检查账号和余额，改好后重做第 5 步，再「全部运行」。T4 没测试过，很可能失败。

**报错里有 `OutOfMemory` 或 `OOM`（显存不够）？**
1. 「代码执行程序 → 重启会话」。
2. 在 ① 设置格把 `LOW_VRAM = False` 改成 `LOW_VRAM = True`。
3. 「代码执行程序 → 全部运行」。
会变慢，但比较不会爆。已经下载的模型不会重新下载。

**中途断线了？**
浏览器分页关掉太久、电脑睡眠、网络中断，都可能让运行时断开；断开后云端电脑里的文件会消失。重新打开 notebook，从第 5 步再来一次。运行期间请让电脑保持不睡眠、分页保持打开。

**成品没有声音？**
先在 ③ 格的音频条试听：那里有声音，说明配音没问题，换一个播放器（例如浏览器或 VLC）打开 mp4 再试；那里也没声音，检查文稿是否是空的。

**嘴型对不上？**
先检查角色图：是不是正面、闭嘴、脸够大、没有被手或麦克风挡住嘴。再检查文稿：语速很快、句子很长的地方比较容易对不准，可以把长句拆短。

**声音不喜欢？**
换 `SEED` 的数字（例如 42 改成 7），或改 `VOICE_DESC` 的描述，再全部运行。

**我想用自己的声音？**
可以，但只能用你本人或已取得当事人同意的录音。做法见 README 的“声音克隆”一节，需要把 `I_HAVE_CONSENT` 改成 `True`，否则 notebook 会直接停止。
