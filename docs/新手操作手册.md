# 新手操作手册

写给**完全没用过 Colab、不会写程序**的人。每一节只做**一个动作**，做完对照「做对了会看到」，对上了再往下。

先认识 4 个词：

- **notebook（笔记本）**：网页上的“程序文件”，由一格一格的内容组成。灰底的是“代码格”，可以运行；白底的是说明文字。本项目就是一个 notebook：`talking_avatar.ipynb`。
- **GPU（显卡）**：做大量计算的硬件，生成声音和视频都靠它。用的是 Google 机房里的，你的电脑不需要有。
- **运行时（runtime）**：Google 临时借你的云端电脑（带 GPU），notebook 在上面运行。用完要删掉，否则会继续计费。
- **计算单元（compute units，也有人叫“运算单元”）**：Colab 的计费点数。用 L4 这种 GPU 会按时间扣点数。

## 准备篇

### 第 1 步：准备一个 Google 账号

**要做的**：确认你有能登录的 Google 账号（Gmail 就是）。

**做对了会看到**：浏览器打开 <https://accounts.google.com>，能看到自己的头像和名称。

### 第 2 步：确认账号里有计算单元

本项目需要 **L4 GPU**，L4 要用**计算单元**。计算单元可在 Colab 付费购买，或由 Google AI Pro 等方案附送；价格以官方页面为准。

**要做的**：用浏览器打开 <https://colab.research.google.com/signup>。

**做对了会看到**：页面显示当前账号的方案和计算单元余额（作者实测，余额在「Pay As You Go」那一栏下方：“您目前有 N 个计算单元。”；以实际显示为准）。余额是 0 的话，后面选 L4 会失败或被降成 T4。

![signup 页面：红框处是计算单元余额](images/01-signup-compute-units.png)

### 第 3 步：确认 Colab 用的是对的账号

**要做的**：如果浏览器同时登录了多个 Google 账号，看右上角头像。Colab 默认用**第一个**账号。

**做对了会看到**：第 2 步页面右上角的头像，就是有计算单元的那个账号。点头像会弹出账号菜单，上方是当前账号的名称和邮箱（下图已涂掉）；登录了多个账号时，点名称右边的箭头可展开其他账号。如果当前不是有计算单元的账号：最简单的办法是开一个“无痕／隐私窗口”，只登录有计算单元的账号，后面都在这个窗口里操作。

![Colab 右上角头像（右上红框）与账号菜单；账号信息已涂掉](images/02-account-menu.png)

## 开始运行

### 第 4 步：打开 notebook

**要做的**：在本项目的 GitHub 页面（README 最上方）点 **Open in Colab** 徽章。

**做对了会看到**：打开 Colab 页面，标题是 `talking_avatar.ipynb`，第一格是说明文字“会说话的主播：一张角色图 + 一段文稿 → 口播视频”。

![notebook 首屏：红框是第一格的标题](images/03-notebook-first-screen.png)

（截图是作者把 notebook 上传到自己的 Google 云端硬盘后打开的；从 GitHub 用 Open in Colab 打开时，标题左边的图标和工具栏按钮可能略有不同。）

### 第 5 步：选择 L4 GPU

**要做的**：点顶部菜单「代码执行程序 → 更改运行时类型」（英文界面：Runtime → Change runtime type）。也可以用「修改 → 笔记本设置」（英文界面：Edit → Notebook settings），是同一个窗口。在“硬件加速器”里选 **L4 GPU**，点「保存」。

本 notebook 已预设 L4，窗口打开时通常已选中；确认是 L4 再点「保存」。

**做对了会看到**：窗口关闭；右上角按钮显示“连接 L4”，点它连接后变成 RAM／磁盘的资源指示，页面右下角显示 `L4（Python 3）`。

![更改运行时类型窗口：L4 GPU 被选中，再点保存](images/05-runtime-type-l4.png)

### 第 6 步：改文稿

**要做的**：找到标题为 `# ① 设置（只需要改这一格）` 的代码格，把 `SCRIPT = """` 和下一个 `"""` 之间的文字换成你的文稿。**一行一句**，每句别太长（超过 80 字会被自动切开）。

**做对了会看到**：三个引号 `"""` 还在原位，中间是你的句子。不想改可跳过，直接用示例文稿。

小技巧：句首可以用括号写语气，例如：

```
(轻松地)大家好，今天聊一个小工具。
(放慢语速，认真地)第一步，先准备一张图。
```

![① 设置格：上面红框是 SCRIPT 文稿，下面红框是第 7 步要改的 VOICE_DESC](images/06-settings-cell-script.png)

### 第 7 步：改音色描述

**要做的**：把 `VOICE_DESC = "..."` 引号里的文字换成你想要的声音描述（性别、年龄、音色、语速、语气）。

**做对了会看到**：引号还在，中间是你的描述。示例：

- `年轻女性，声音清亮自然，语速中等，语气亲切平稳，像新闻主播在播报`
- `中年男性，嗓音低沉温和，语速偏慢，语气沉稳可靠，像纪录片旁白`
- `二十多岁的男生，声音明亮有活力，语速稍快，语气轻松，像在和朋友聊天`

不满意可以之后换 `SEED` 的数字再跑一次，同样的描述也会生成不同的声音。

### 第 8 步：上传自己的角色图（不换图可跳过）

**要做的**：点 Colab 左侧的**文件夹图标**（「文件」面板），再点面板上方的“上传”图标，选电脑里的图片。

要先连上运行时：面板里没有文件列表的话，先点右上角「连接」，等文件列表（`sample_data` 等）出现再上传。

**做对了会看到**：文件列表里出现你的图片（在 `/content/` 文件夹里）。Colab 会弹出“警告：确保您的文件已保存到其他位置。此运行时终止后，此运行时的文件将被删除。”，点「确定」。

图片要求：

- **竖图**（高比宽长），人物**正面**看镜头；
- **闭着嘴**；
- **脸够大**（上半身入镜就好，不要全身照）；
- **手不要入镜**；
- 只能用你本人、已取得同意的人、或 AI 生成的虚构人物。

文件名建议用英文或数字（例如 `me.png`）。

![左侧文件面板：左边红框是文件夹图标，上方红框是“上传”图标，下方红框是上传后的图片](images/08-file-panel-upload.png)

### 第 9 步：把 IMAGE_PATH 改成你的图

**要做的**：在 ① 设置格里，把 `IMAGE_PATH = "examples/host.png"` 改成 `IMAGE_PATH = "/content/你的图.png"`（换成实际文件名，大小写要一致）。

**做对了会看到**：一行 `IMAGE_PATH = "/content/me.png"` 这样的内容。拿不准文件名，就在文件面板里右键图片 →「复制路径」，再粘贴进引号里。

### 第 10 步：全部运行

**要做的**：点顶部菜单「代码执行程序 → 全部运行」（英文界面：Runtime → Run all）。

**做对了会看到**：正在运行的代码格左边按钮变成转圈图标，跑完的格变成绿色的勾；页面右下角显示“正在执行（已持续 N 秒）”。① 和 ② 格几秒内跑完，之后 ③ 格会转圈好几分钟，正常。

### 第 11 步：处理安全警告

**要做的**：弹出“警告：此笔记本不是由 Google 创作”的窗口时，点「**仍然运行**」（英文界面：Run anyway）。

**做对了会看到**：窗口关闭，代码格继续一格一格运行。过了半分钟还没有格在转圈，再点一次「全部运行」。

没弹出窗口也没关系，直接看下一步。作者实测：把 notebook 上传到自己的云端硬盘再运行，没有弹出这个窗口。

<!-- 截图：“此笔记本不是由 Google 创作”警告窗口，标出“仍然运行” -->

### 第 12 步：等待并查看进度

**要做的**：保持浏览器分页开着，等，什么都不用做。

**做对了会看到**：

- ② 格打印 `GPU：NVIDIA L4，显存 22.x GiB`（出现 `⚠ 警告` 就看下方“常见问题”）。
- ③ 格逐句打印配音进度，跑完出现可播放的音频条，可以先试听。
- ④-5 格每 30 秒打印一行 `[ xxx 秒] ...` 进度，这是最久的一步。

要等多久：作者实测示例文稿（配音 10.88 秒，对嘴分 4 段），从 ② 格开始到 ⑤ 格跑完共约 22 分钟，其中对嘴约 16 分钟；另一次 21.5 秒的成品，光对嘴就约 36 分钟。文稿越长越久。

![④-5 格运行中：每 30 秒一行进度](images/12-lipsync-progress.png)

进度条每走完 6 步是生成完一段，接着回到 `0/6` 开始下一段，正常。

### 第 13 步：下载成品

**要做的**：等最后的 ⑤ 格打印出 `====` 框。浏览器会自动下载 `talking_avatar.mp4`；问“是否允许下载”就点允许。

**做对了会看到**：下载文件夹里有 `talking_avatar.mp4`，⑤ 格下方也能直接播放视频。没自动下载的话：左侧文件面板 → `output` 文件夹 → 右键 `talking_avatar.mp4` →「下载」。

![⑤ 格：红框是 ==== 框（GPU、成品路径、各步耗时），下方是视频预览](images/13-output-box-video.png)

### 第 14 步：删除运行时（一定要做）

**要做的**：点顶部菜单「代码执行程序 → 断开连接并删除运行时」（英文界面：Runtime → Disconnect and delete runtime）。

![代码执行程序菜单：红框是“断开连接并删除运行时”](images/14-disconnect-delete-runtime.png)

弹出确认窗口“确定要重置此运行时吗？此运行时的状态（包括所有本地变量和文件）将会丢失。”，点「是」。**注意：如果弹出的是写着“警告”、提醒文件会被删除的窗口，按「确定」后，要再点一次「断开连接并删除运行时」才真正删除。**

**做对了会看到**：右上角变成“重新连接”按钮，左侧文件面板显示“连接到某个运行时可启用文件浏览功能”。想再确认：「代码执行程序 → 管理会话」显示“没有正在进行的会话”就对了。不删的话，你什么都不做也会继续扣计算单元。

## 常见问题

**② 格出现警告，GPU 显示 T4，不是 L4？**
通常是账号没有计算单元或余额是 0，被降成 T4。回第 2、3 步检查账号和余额，改好后重做第 5 步，再「全部运行」。T4 没测试过，很可能失败。

**报错里有 `OutOfMemory` 或 `OOM`（显存不够）？**
1. 「代码执行程序 → 重启会话」。
2. 在 ① 设置格把 `LOW_VRAM = False` 改成 `LOW_VRAM = True`。
3. 「代码执行程序 → 全部运行」。
会变慢，但比较不会爆。已下载的模型不会重新下载。

**中途断线了？**
分页关太久、电脑睡眠、网络中断都会让运行时断开，云端的文件会消失。重新打开 notebook，从第 5 步再来一次。运行期间让电脑保持不睡眠、分页保持打开。

**成品没有声音？**
先在 ③ 格的音频条试听。那里有声音：配音没问题，换个播放器（浏览器或 VLC）打开 mp4。那里也没声音：检查文稿是不是空的。

**嘴型对不上？**
先检查角色图：是否正面、闭嘴、脸够大、嘴没被手或麦克风挡住。再看文稿：语速很快、句子很长的地方容易对不准，把长句拆短。

**声音不喜欢？**
换 `SEED` 的数字（例如 42 改成 7），或改 `VOICE_DESC`，再全部运行。

**我想用自己的声音？**
可以，但只能用你本人或已取得当事人同意的录音。做法见 README 的“声音克隆”一节，需要把 `I_HAVE_CONSENT` 改成 `True`，否则 notebook 会直接停止。
